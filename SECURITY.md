# Security Policy

## Reporting a Vulnerability

Troc is an early prototype forked from Bull Bitcoin Mobile. It is not affiliated with Bull Bitcoin.

- **Vulnerabilities in Troc's own code** (the P2P / RoboSats integration, this repository's CI): report them privately through GitHub's [private vulnerability reporting](https://github.com/Skyman21m/troc/security/advisories/new). Do not send them to Bull Bitcoin.
- **Vulnerabilities that also affect the upstream wallet**: please report them to the upstream project as well, following the [Bull Bitcoin Mobile security policy](https://github.com/SatoshiPortal/bullbitcoin-mobile/security/policy).

Do not open a public issue for security reports.

Include as much detail as possible (affected version or commit, steps to reproduce, impact).

See [docs/SECURE_DEVELOPMENT.md](docs/SECURE_DEVELOPMENT.md) for the secure development practices this app follows.
